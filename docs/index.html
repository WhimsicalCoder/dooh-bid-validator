DOOH Bid Request Validator

Buyer-side tools for programmatic DOOH (OpenRTB 2.6): check bid requests, and find the same screen sold through several SSPs.

● Runs entirely in your browser. Nothing you paste is sent anywhere.

Checks screen location, venue type, impression multiplier, play time and creative. Each issue names the spec section it comes from.

Bid request

Report

Paste a bid request or load a sample, then press Validate.
Tip: Ctrl/⌘ + Enter also runs it.

Paste DOOH bid requests from several SSPs. Requests are grouped into listings (one per SSP per screen ID), then listings that describe the same physical screen are matched by distance, size, venue, publisher and name. For each shared screen you see every SSP's supply path, audience multiplier, floor and cost per play.

Bid requests

Report

Paste bid requests from several SSPs, or load the sample batch, then press Find duplicates.
Open source (Apache 2.0): github.com/WhimsicalCoder/dooh-bid-validator. Based on OpenRTB 2.6, the IAB Tech Lab DOOH implementation guide, AdCOM 1.0 and the OpenOOH venue taxonomy.
