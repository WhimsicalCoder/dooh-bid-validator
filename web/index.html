DOOH Bid Request Validator

Check programmatic DOOH bid requests (OpenRTB 2.6) from a buyer's point of view: screen location, venue type, impression multiplier, play time and creative. Each issue names the spec section it comes from.

● Runs entirely in your browser. Nothing you paste is sent anywhere.

Paste a bid request or load a sample, then press Validate.
Tip: Ctrl/⌘ + Enter also runs it.
Open source (Apache 2.0): github.com/WhimsicalCoder/dooh-bid-validator. Based on OpenRTB 2.6, the IAB Tech Lab DOOH implementation guide, AdCOM 1.0 and the OpenOOH venue taxonomy.
